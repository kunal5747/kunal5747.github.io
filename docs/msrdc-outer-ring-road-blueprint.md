# MSRDC Outer Ring Road (Pune) — Blueprint

Compiled 2026-09-05 from public sources (MSRDC/PMRDA, Wikipedia, The Metro Rail Guy,
ConstructionWorld, DeshGujarat). Figures vary by source — variances flagged inline.
Not a substitute for the sanctioned alignment plan / 7-12 + Bhoosampadan notifications.

## 1. Headline numbers

| Item | Value |
|---|---|
| Owner | MSRDC (Maharashtra State Road Development Corporation) |
| Official name | Pune Ring Road (Outer) — greenfield, access-controlled |
| Length | 136.8 km carriageway (168.94 km incl. link/spur alignments) |
| Split | West 65.45 km · East 71.35 km |
| Lanes | 6-lane (97.8 km) + 4-lane (39 km), lane width 3.75 m |
| ROW | 90–110 m |
| Design speed | 120 kmph |
| Structures | 8 tunnels = 11.29 km; 0.5 km bridge across Khadakwasla backwater |
| Civil cost | ₹15,857 cr (tendered) · ₹10,408 cr often quoted as base cost |
| Land acquisition | ~₹11,000 cr across 83 villages |
| Talukas | Khed, Haveli, Purandar, Bhor, Mulshi, Maval (Pune district) |
| Termini / loop | Urse (Mumbai–Pune Expressway) → Alandi/Chimbali → Lonikand → Valati → Sonori → Garade → Shivare/Khed Shivapur → back to Urse |
| Construction start | Dec 2024 (west), staged |
| Target | West 2026–27 · East 2028 · full corridor by 2030 (working deadline) |

## 2. Alignment sections

1. **Eastern Part-1** — Urse → Solu (≈40 km shared corridor with PMRDA Inner Ring Road)
2. **Eastern Part-2** — Solu → Varve (Kelawade)
3. **Western** — Urse → Varve

Corridor is a full loop outside PMC/PCMC, intercepting NH-48 (Mumbai–Pune),
Pune–Nashik (NH-60), Pune–Ahmednagar (NH-753F), Pune–Solapur (NH-65),
Pune–Satara (NH-48 south), Pune–Bengaluru and the Mumbai–Pune Expressway.
15 interchange locations planned; 12 have committed connectivity, 3 proposed.

## 4. Land acquisition status

- 83 villages notified; ~₹11,000 cr compensation outlay.
- Sept 2024: West ~90% acquired, East ~70%.
- 2025–26: West reported 99%+ acquired; East acquisition continuing, Purandar/Bhor
  stretch (E5–E7) is the lagging block.
- Compensation route: mostly direct purchase / consent award at multiples of ready
  reckoner (2x–5x band depending on village and mode), plus 25% incentive where
  landowners consented under the direct-purchase policy.
- Named villages appearing in package descriptions: Urse, Kemsewadi, Morewadi,
  Vardade, Khamgaon, Kalyan, Rahatwade, Shivare, Kusgaon, Indori, Chimbali, Solu,
  Lonikand, Kesnand, Wadebolhai, Valati, Sonori, Garade, Shiware, Varve/Kelawade,
  Khalumbe, Nigije, Moi, Kuruli, Kelgaon, Alandi, Charholi, Dhanori.
  (Full 83-village schedule is only in the MSRDC notification/gazette — pull from
  the Bhoosampadan office or IGR village-wise records before relying on it.)

## 5. Due-diligence checklist for any plot on the alignment

1. Get the village name + Gat/Survey no.; check it against the MSRDC 3(a)/3(d)
   notification and the ROW plan (90–110 m band).
2. 7/12 utara — check for "Bhoosampadan / MSRDC" or "sampadit" remarks and any
   varas/other rights entry.
3. Run a 42-year IGR eSearch (Index II) on the Gat no. for prior sales, mortgages,
   power-of-attorney chains.
4. Confirm whether the plot is inside the ROW (acquired, price fixed by state) or
   in the influence belt (market-priced, upside play) — the two are financially
   opposite.
5. Check zoning: PMRDA Development Plan / Regional Plan, green belt, ceiling on
   NA conversion, and any interchange-adjacent reservation.
6. For E5–E7 (Purandar/Bhor), award and construction are still pending — timeline
   risk is 2–4 years longer than the western side.
