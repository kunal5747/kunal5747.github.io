# Finance Kit — Kunal's construction business

Practical playbooks + templates for raising and managing money in a
construction JV business run as a 3-partner family operation in India.
Written around real numbers from the live 90,600 sq ft JV deal
(₹1.6 cr deposit / ₹1.45 cr sanction / ₹2 cr construction cash / 41.5%
landowner share).

## Contents

| File | What it teaches |
| --- | --- |
| `01-overdraft-and-cc.md` | Getting and using OD / cash-credit limits — the cheapest flexible money |
| `02-business-loans.md` | Term loans, LAP, CGTMSE, construction finance — how banks actually decide |
| `03-money-management.md` | Account structure, reserves, the discipline rules that prevent blowups |
| `04-fundraising-playbook.md` | Raising private capital at ≤2%/month: sources, structures, the raise kit |
| `jv-deal-model.html` | Interactive cash-flow model (open in a browser; also deployed as a Claude artifact) |
| `templates/partner-capital-allocation-agreement.md` | 3-partner family capital + profit allocation agreement |
| `templates/investor-loan-term-sheet.md` | Fixed-return (e.g. 2%/month) private loan term sheet |
| `templates/profit-share-term-sheet.md` | SPV/LLP profit-share investment with waterfall |
| `templates/investor-one-pager.md` | The single page that raises money — with the live deal as example |

## How to use this with Claude

This folder is read by Claude in any session on this repo. Ask things like:

- "Using my finance kit, size the OD limit I should ask for with ₹X turnover"
- "Fill the investor one-pager for this new deal: …"
- "Draft the allocation agreement for our three partners with these numbers"
- "Check this loan offer against the negotiation checklist"

## Non-negotiable disclaimer

Every template here is an **educational draft** to make your conversation
with professionals faster and cheaper — it is not legal or financial advice.
Before signing anything: have a CA review the tax/TDS treatment and an
advocate review enforceability, stamp duty, and registration for your state.
Laws referenced (RERA, Companies Act deposit rules, state money-lending
acts, TDS sections) change — verify current provisions.
